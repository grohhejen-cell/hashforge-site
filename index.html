What is HASHFORGE?

HASHFORGE aims to develop an independent blockchain where compatible miners use computing power to compete to produce valid blocks. Network nodes verify blocks and transactions according to published protocol rules.

⛓ Proof of Work

Blocks must satisfy the network's difficulty target and pass independent validation.

🖥 GPU Mining

The project plans to evaluate a suitable mining algorithm and compatible GPU software.

🔎 Transparency

Protocol rules, issuance, software and development progress should be publicly documented.

GPU Mining & Rewards

The proposed HFG reward would be issued under the blockchain's consensus rules for valid blocks. Rewards are not available yet: the network and miner must be implemented and tested first.

Status: Early concept. No live HFG mining, token market price, exchange listing or guaranteed earnings are claimed.

Project Roadmap

Phase 1 — Foundation

Publish project goals, documentation and an open development repository.

Phase 2 — Testnet

Build and test block validation, difficulty adjustment, wallets and block rewards using test coins.

Phase 3 — GPU Miner

Benchmark compatible hardware and test mining performance and power consumption.

Phase 4 — Security Review

Arrange independent testing before considering any public mainnet launch.
